# ASCA Tutorial

This repository contains the code for reproducing the results of the paper Camacho et al. ANOVA Simultaneous Component Analysis. A Tutorial Review. Submitted to Journal of Chemometrics.

This repository requires the MEDA toolbox v1.11 at https://github.com/codaslab/MEDA-Toolbox

Contact person: José Camacho (josecamacho@ugr.es)

Last modification of this document: 26/Feb/26



## Organization

The folder contains:

* The script named analysisTN\_ASCA.m performs the leading example of the paper.
* The tex files contain the resulting ASCA tables.
* The excel file contains the input data.
* Figures/ contains the figures generated by the examples.
* html/ contains the publication of results with the Matlab command 'publish'.



## How to use

Install the MEDA Toolbox v1.11 and this repository, and execute "analysisTN\_ASCA".
